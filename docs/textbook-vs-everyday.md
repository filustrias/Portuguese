# Textbook vs. everyday Portuguese

The Pimsleur course deliberately uses a very formal, teaching register: *o senhor*, *a senhora*, *minha senhora*, and *eu* and *você* repeated in almost every sentence. That makes the structures easy to hear, but it is not how people talk in Portugal. This table collects, from lessons 1 to 10, what the course says and what you will hear on the street.

| Pimsleur | Everyday Portugal | Context |
|:--|:--|:--|
| *Com licença, minha senhora.* | *Olhe, desculpe...* / *Faz favor...* | Approaching a stranger in town. ([Lesson 01](./pimsleur_portuguese_01.md)) |
| *O senhor / A senhora fala inglês?* | *Fala inglês?* / *Falas inglês?* | Drop the pronoun, or use *tu* with people you know. ([Lesson 03](./pimsleur_portuguese_03.md)) |
| *Eu não o percebo / não a percebo.* | *Não estou a perceber nada.* / *Desculpe, não apanhei.* | Not following what someone just said. ([Lesson 03](./pimsleur_portuguese_03.md)) |
| *Eu chamo-me [name].* | *Sou o [name].* / *O meu nome é [name].* | Introducing yourself; first names take the article. ([Lesson 02](./pimsleur_portuguese_02.md)) |
| *Adeus.* | *Até logo.* / *Até já.* / *Tchau.* | A warmer goodbye. ([Lesson 04](./pimsleur_portuguese_04.md)) |
| *O que é que você quer comer?* | *O que é que te apetece comer?* / *O que vai ser?* | Offering food or drink without sounding abrupt. ([Lesson 08](./pimsleur_portuguese_08.md)) |
| *Um pastel de nata.* | *Uma nata.* | At the counter of a Lisbon café. ([Lesson 07](./pimsleur_portuguese_07.md)) |
| *Uma água mineral com gelo.* | *Uma água fresca com uma pedra de gelo.* | Ordering water in a café or on a terrace. ([Lesson 08](./pimsleur_portuguese_08.md)) |
| *Onde é que fica a casa de banho?* | *Onde é a casa de banho, se faz favor?* | Asking for the toilet; never *banheiro*. ([Lesson 08](./pimsleur_portuguese_08.md)) |
| *Na minha casa eu tenho...* | *Em casa tenho...* / *Tenho lá em casa...* | Talking about home. ([Lesson 07](./pimsleur_portuguese_07.md)) |
| *Quero uma bica.* | *Era uma bica / um café, se faz favor.* | The polite past tense used for ordering at the counter. ([Lesson 10](./pimsleur_portuguese_10.md)) |
| *Eu vou pagar.* | *Deixa estar que pago eu!* / *Fica por minha conta.* | The ritual of offering to pay in cafés and bars. ([Lesson 09](./pimsleur_portuguese_09.md)) |
| *Você é americano, não é?* | *És americano, não és?* | Tag question between friends. ([Lesson 06](./pimsleur_portuguese_06.md)) |
| *Alguns euros.* | *Uns trocos.* / *Dois paus.* | Small amounts of money; *paus* is slang. ([Lesson 06](./pimsleur_portuguese_06.md)) |
| *Está bem.* | *'Tá bem.* / *Combinado.* / *Siga.* | Agreeing, everyday. ([Lesson 07](./pimsleur_portuguese_07.md)) |

## Three rules of thumb

**Avoid saying *você*.** Leave it out and keep the verb, use the person's name with the article, use *o senhor* / *a senhora*, or switch to *tu* with friends. See [Lesson 03](./pimsleur_portuguese_03.md).

**Leave out *eu*.** The verb ending already says who is speaking. Use *eu* only for contrast: *Eu pago!* (<Lat>EH-oo PAH-goo!</Lat> - I'll pay!, not you).

**Answer with the verb.** *Tens tempo?* → *Tenho.* (<Lat>TUH-nyoo.</Lat> - I have.) sounds more natural than a bare *sim*.
