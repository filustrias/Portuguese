# Textbook vs. everyday Portuguese

The Pimsleur course deliberately uses a very formal, teaching register: *o senhor*, *a senhora*, *minha senhora*, and *eu* and *você* repeated in almost every sentence. That makes the structures easy to hear, but it is not how people talk in Portugal. This table collects, from lessons 1 to 20, what the course says and what you will hear on the street.

| Pimsleur | Everyday Portugal | Context |
|:--|:--|:--|
| *Com licença, minha senhora.* | *Olhe, desculpe...* / *Faz favor...* | Approaching a stranger in town. ([Lesson 01](./pimsleur_portuguese_01.md)) |
| *O senhor / A senhora fala inglês?* | *Fala inglês?* / *Falas inglês?* | Drop the pronoun, or use *tu* with people you know. ([Lesson 03](./pimsleur_portuguese_03.md)) |
| *Eu não o percebo / não a percebo.* | *Não estou a perceber nada.* / *Desculpe, não apanhei.* | Not following what someone just said. ([Lesson 03](./pimsleur_portuguese_03.md)) |
| *Eu chamo-me [name].* | *Sou o [name].* / *O meu nome é [name].* | Introducing yourself; first names take the article. ([Lesson 02](./pimsleur_portuguese_02.md)) |
| *Adeus.* | *Até logo.* / *Até já.* / *Tchau.* | A warmer goodbye. ([Lesson 04](./pimsleur_portuguese_04.md)) |
| *O que é que você quer comer?* | *O que é que te apetece comer?* / *O que vai ser?* | Offering food or drink without sounding abrupt. ([Lesson 08](./pimsleur_portuguese_08.md)) |
| *Um pastel de nata.* | *Uma nata.* | At the counter of a Lisbon café. ([Lesson 07](./pimsleur_portuguese_07.md)) |
| *Uma água mineral com gelo.* | *Uma água fresca com uma pedra de gelo.* | Ordering water in a café or on a terrace. ([Lesson 08](./pimsleur_portuguese_08.md)) |
| *Onde é que fica a casa de banho?* | *Onde é a casa de banho, se faz favor?* | Asking for the toilet; never *banheiro*. ([Lesson 08](./pimsleur_portuguese_08.md)) |
| *Na minha casa eu tenho...* | *Em casa tenho...* / *Tenho lá em casa...* | Talking about home. ([Lesson 07](./pimsleur_portuguese_07.md)) |
| *Quero uma bica.* | *Era uma bica / um café, se faz favor.* | The polite past tense used for ordering at the counter. ([Lesson 10](./pimsleur_portuguese_10.md)) |
| *Eu vou pagar.* | *Deixa estar que pago eu!* / *Fica por minha conta.* | The ritual of offering to pay in cafés and bars. ([Lesson 09](./pimsleur_portuguese_09.md)) |
| *Você é americano, não é?* | *És americano, não és?* | Tag question between friends. ([Lesson 06](./pimsleur_portuguese_06.md)) |
| *Alguns euros.* | *Uns trocos.* / *Dois paus.* | Small amounts of money; *paus* is slang. ([Lesson 06](./pimsleur_portuguese_06.md)) |
| *Está bem.* | *'Tá bem.* / *Combinado.* / *Siga.* | Agreeing, everyday. ([Lesson 07](./pimsleur_portuguese_07.md)) |
| *Quero um pastel de nata.* | *Era um pastel de nata, se faz favor.* | The polite imperfect softens an order at the counter. ([Lesson 11](./pimsleur_portuguese_11.md)) |
| *A água está gelada?* | *Tem água fresca?* / *Bem fresca, se tiver.* | *Gelada* sounds almost frozen; ask for *fresca*. ([Lesson 11](./pimsleur_portuguese_11.md)) |
| *Tem gelo?* | *Pode deitar umas pedras de gelo?* | Ice cubes are *pedras de gelo*. ([Lesson 11](./pimsleur_portuguese_11.md)) |
| *Eu vou pagar. / Eu quero pagar.* | *Deixa estar, pago eu!* / *Nem penses, hoje fica por minha conta!* | Fighting over the bill; the pronoun goes after the verb. ([Lesson 12](./pimsleur_portuguese_12.md)) |
| *Pode comer hoje às duas?* | *Dá-te jeito almoçarmos às duas?* | Use the verb for the meal and *dar jeito*. ([Lesson 13](./pimsleur_portuguese_13.md)) |
| *Um quarto para as cinco.* | *Quinze para as cinco.* | Younger speakers count the minutes. ([Lesson 13](./pimsleur_portuguese_13.md)) |
| *Eu pago. Posso pagar?* | *Convido eu!* / *Deixa isso por minha conta.* | Offer, don't ask permission. ([Lesson 14](./pimsleur_portuguese_14.md)) |
| *É muito gentil.* | *É muito simpático da sua parte!* / *És um querido!* | Thanking someone for a kindness. ([Lesson 14](./pimsleur_portuguese_14.md)) |
| *Que horas são?* | *Desculpe, tem horas?* | Asking a stranger the time. ([Lesson 14](./pimsleur_portuguese_14.md)) |
| *Quero conversar consigo.* | *Tens um minuto?* / *Queria falar contigo.* | *Falar* for a quick word; *consigo* is formal only. ([Lesson 15](./pimsleur_portuguese_15.md)) |
| *É demais.* | *É um exagero!* | *É demais!* in slang often means "it's amazing". ([Lesson 15](./pimsleur_portuguese_15.md)) |
| *Vamos beber cerveja?* | *Bora beber uma imperial?* / *um fino* / *uma jola* | Draught beer: *imperial* in Lisbon, *fino* in Porto. ([Lesson 16](./pimsleur_portuguese_16.md)) |
| *O meu amigo e eu queremos ir jantar com a senhora.* | *Quer vir jantar connosco?* | Put the guest at the centre of the invitation. ([Lesson 17](./pimsleur_portuguese_17.md)) |
| *Quero comprar alguma coisa de Portugal.* | *Andava à procura de uma lembrança típica.* | Shopping for a souvenir. ([Lesson 18](./pimsleur_portuguese_18.md)) |
| *Quanto é que o senhor quer gastar?* | *Até que valor é que estava a pensar?* | A polite shop assistant's question. ([Lesson 18](./pimsleur_portuguese_18.md)) |
| *É suficiente?* | *Achas que chega?* / *Dá tempo?* | Is there enough time or food. ([Lesson 19](./pimsleur_portuguese_19.md)) |
| *Trinta minutos.* | *Meia hora.* / *Uma meia horita.* | A short break. ([Lesson 19](./pimsleur_portuguese_19.md)) |
| *Eu sou João Smith.* | *Sou o João.* / *Chamo-me João Smith.* | Introducing yourself. ([Lesson 20](./pimsleur_portuguese_20.md)) |
| *Porque me vou embora.* | *Tenho mesmo de me pôr a andar!* | Leaving politely, with a reason. ([Lesson 20](./pimsleur_portuguese_20.md)) |

## Three rules of thumb

**Avoid saying *você*.** Leave it out and keep the verb, use the person's name with the article, use *o senhor* / *a senhora*, or switch to *tu* with friends. See [Lesson 03](./pimsleur_portuguese_03.md).

**Leave out *eu*.** The verb ending already says who is speaking. Use *eu* only for contrast: *Eu pago!* (<Lat>[ew ˈpaɡu]</Lat> - I'll pay!, not you).

**Answer with the verb.** *Tens tempo?* → *Tenho.* (<Lat>[ˈtɐɲu]</Lat> - I have.) sounds more natural than a bare *sim*.
